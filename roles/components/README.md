# pokerops.rke2.components

Standard cluster components for RKE2 clusters.

## Role Variables

| Parameter                                  |                        Default | Type   | Description                                                                                                                                                                                                                    | Required |
| :----------------------------------------- | -----------------------------: | :----- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------- |
| rke2_argocd_hostname                       | argocd.{{ rke2_cluster_name }} | string | Argocd URL                                                                                                                                                                                                                     | no       |
| rke2_certmanager_issuer_name               |                 cluster-issuer | string | Name of the cert-manager cluster issuer                                                                                                                                                                                        | no       |
| rke2_monitoring_endpoint                   |                                | string | Remote ingestor URL; setting it enables monitoring                                                                                                                                                                             | no       |
| rke2_logging_endpoint                      |                                | string | Remote ingestor host:port; setting it enables logging                                                                                                                                                                          | no       |
| rke2_monitoring_cluster_id                 |        {{ rke2_cluster_name }} | string | Cluster label stamped on every metric and log record                                                                                                                                                                           | no       |
| rke2_monitoring_tls_enabled                |                          false | bool   | Use mTLS to reach the remote ingestor                                                                                                                                                                                          | no       |
| rke2_seaweedfs_logs_enable                 |                          false | bool   | Deploy a local SeaweedFS log store + POSIX mount; setting it enables logging even with no remote endpoint                                                                                                                      | no       |
| rke2_seaweedfs_logs_namespace              |                 seaweedfs-logs | string | Namespace for the local log retention SeaweedFS cluster                                                                                                                                                                        | no       |
| rke2_seaweedfs_logs_image                  |       chrislusf/seaweedfs:4.48 | string | SeaweedFS image for the cluster; its tag also selects the host `weed` binary version                                                                                                                                           | no       |
| rke2_seaweedfs_logs_bucket                 |                           logs | string | Bucket name backing the local log retention mount                                                                                                                                                                              | no       |
| rke2_seaweedfs_logs_storage_class          |                 seaweedfs-logs | string | Storage class for the local log retention volume                                                                                                                                                                               | no       |
| rke2_seaweedfs_logs_volume_size            |                           10Gi | string | Disk size for the local log retention cluster (one disk per `volumeServerDiskCount: 1` - the actual capacity budget, not multiplied by max_volume_count); size for 2x the retention window at your cluster's observed log rate | no       |
| rke2_seaweedfs_logs_max_volume_count       |                              7 | int    | How many SeaweedFS volume files can exist within that one disk; too low silently exhausts itself on other collections                                                                                                          | no       |
| rke2_seaweedfs_logs_volume_size_limit_mb   |                           1300 | int    | Per-volume size ceiling in MB; keep max_volume_count x this under the disk size less min_free_space_percent                                                                                                                    | no       |
| rke2_seaweedfs_logs_retention_days         |                              1 | int    | Days before a log file ages out (whole days only)                                                                                                                                                                              | no       |
| rke2_seaweedfs_logs_min_free_space_percent |                             10 | int    | Free-space threshold below which a volume is marked read-only (so the master allocates a fresh one) instead of hitting a hard ENOSPC                                                                                           | no       |
| rke2_seaweedfs_logs_mount_path             |               /var/log/cluster | string | Host path every node mounts the logs bucket at - agents write, server nodes read                                                                                                                                               | no       |
